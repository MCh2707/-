# ბაღების აღრიცხვის სისტემა

საბავშვო ბაღების ყოველდღიური დასწრებისა და კვების მონაცემების აღრიცხვის, მართვისა და სტატისტიკური ანალიზის ვებ-აპლიკაცია.

სისტემა შექმნილია რეალური სამუშაო პროცესისთვის და ამჟამად გამოიყენება 63 საბავშვო ბაღის მონაცემების სამართავად.

**Live Application:** http://baghis-aghritskhva.runasp.net/

---

## პროექტის შესახებ

ბაღების აღრიცხვის სისტემა შეიქმნა ყოველდღიური მონაცემების აღრიცხვის პროცესის გასამარტივებლად და გასაციფრულებლად.

თითოეულ ბაღს აქვს საკუთარი ანგარიში, რომლის საშუალებითაც შესაძლებელია მიმდინარე დღის ბავშვების რაოდენობის შეყვანა. სისტემაში შენახული მონაცემები შემდგომ გამოიყენება სტატისტიკისა და სხვა საჭირო გამოთვლებისათვის.

ადმინისტრატორს აქვს სისტემის მომხმარებლებისა და მონაცემების მართვის შესაბამისი შესაძლებლობები.

პროექტის ერთ-ერთი მნიშვნელოვანი ნაწილი არის კვების პროდუქტების ავტომატური გამოთვლის სისტემა, რომელიც ბავშვების რაოდენობისა და კონკრეტული დღის ნორმების მიხედვით განსაზღვრავს საჭირო პროდუქტების რაოდენობას.

## ტექნოლოგიური სტეკი

### პროგრამირების ენები

**C# (.NET 8)**
აპლიკაციის ძირითადი პროგრამირების ენა. გამოიყენება როგორც Backend ბიზნეს-ლოგიკისთვის, ასევე Blazor-ის UI კომპონენტების სამართავად.

**HTML5 & Razor Syntax**
აპლიკაციის სტრუქტურისა და დინამიური კომპონენტების შესაქმნელად.

**CSS3**
ვიზუალური დიზაინის, Layout-ისა და Responsive ინტერფეისის შესაქმნელად.

**LINQ**
მონაცემების გაფილტვრის, დამუშავებისა და აგრეგაციისთვის.

### Frameworks & Platform

**ASP.NET Core 8.0 / Blazor Web App**
აპლიკაციის ძირითადი Web Framework. გამოყენებულია `InteractiveServer` rendering რეჟიმი ინტერაქტიული UI-ის შესაქმნელად.

**Entity Framework Core 8**
ORM ფენა, რომელიც უზრუნველყოფს C# აპლიკაციასა და მონაცემთა ბაზას შორის ურთიერთქმედებას.

### მონაცემთა ბაზა

**SQLite**
მსუბუქი relational database, რომელიც გამოიყენება სისტემის ძირითადი მონაცემების შესანახად.

მონაცემთა ბაზაში ინახება:

* საბავშვო ბაღების მონაცემები და ოფიციალური სახელწოდებები
* მომხმარებელთა ანგარიშები
* ავტორიზაციასთან დაკავშირებული მონაცემები
* ყოველდღიური დასწრების ჩანაწერები

## არქიტექტურა

პროექტში ბიზნეს-ლოგიკის ძირითადი ნაწილები გამოყოფილია სპეციალიზებულ სერვისებად.

### AttendanceService

პასუხისმგებელია დასწრების მონაცემებთან დაკავშირებულ ოპერაციებზე:

* ყოველდღიური ჩანაწერების შენახვა
* მონაცემების მიღება
* თარიღების მიხედვით გაფილტვრა
* თვიური სტატისტიკა
* წლიური სტატისტიკა

### MenuCalculationService

ახორციელებს კვების პროდუქტების საჭირო რაოდენობის ავტომატურ გამოთვლას.

სერვისი ითვალისწინებს:

* 28 სხვადასხვა პროდუქტს
* კვირის დღეების მიხედვით განსხვავებულ ნორმებს
* ბავშვების რაოდენობას
* პროდუქტის საჭირო რაოდენობის გამოთვლას

### UserSessionState

მართავს მომხმარებლის მიმდინარე ავტორიზაციისა და სესიის მდგომარეობას.

მოიცავს:

* მიმდინარე მომხმარებლის მდგომარეობას
* ავტორიზაციის სტატუსს
* მომხმარებლის შესაბამისი მონაცემების მართვას
* წვდომის კონტროლთან დაკავშირებულ მდგომარეობას

## გამოყენების მიზანი

სისტემის მიზანია საბავშვო ბაღების ყოველდღიური აღრიცხვის პროცესის გაციფრულება და ცენტრალიზებული მართვა.

აპლიკაცია ამცირებს ხელით შესასრულებელი სამუშაოს მოცულობას, უზრუნველყოფს მონაცემების ერთიან სისტემაში შენახვას და ავტომატიზაციას უკეთებს იმ გამოთვლებს, რომლებიც მანამდე ცალკე შესრულებას საჭიროებდა.
